# 🎯 Exactly 4 Divisors Math

A number has exactly 4 divisors in TWO cases:

**Case 1: p³ (cube of prime)**
- 8 = 2³ → {1, 2, 4, 8}
- 27 = 3³ → {1, 3, 9, 27}

**Case 2: p×q (product of two distinct primes)**
- 6 = 2×3 → {1, 2, 3, 6}
- 21 = 3×7 → {1, 3, 7, 21}
- 15 = 3×5 → {1, 3, 5, 15}
